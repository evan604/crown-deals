## Executive Summary

**CrownDeals** is the first vertical under the **CollectorIQ** umbrella brand. It uses AI-powered deal intelligence to help Rolex and luxury watch buyers navigate the gray market with confidence.

**The Problem:** Gray market watch buyers spend hours manually comparing prices across Chrono24, Bob's Watches, WatchBox, and eBay, with no reliable way to know if they're overpaying.

**The Solution:** CrownDeals monitors 50+ sources in real-time, applies AI-powered scoring (0-10), and delivers personalized deal alerts via email, SMS, and web dashboard.

**Why This Works:**
- High-intent buyers with significant disposable income
- Opaque pricing creates genuine information asymmetry
- $50K average purchase justifies $49/month subscription
- 2-5% affiliate commissions on luxury watches = $250-1,250 per sale

## Product Overview

### Core Features (MVP)

**1. Multi-Source Scraping Engine**
- Chrono24, Bob's Watches, WatchBox, eBay, Mercari, Amazon
- Rolling schedule: every 15 minutes for eBay, 2 hours for retail sites
- Managed by Apify with anti-bot protection

**2. AI Deal Scoring**
- Each listing scored 0-10 based on weighted factors:
  - Price vs. 90-day historical average (35%)
  - Price vs. retail/gray market benchmark (25%)
  - Condition & completeness (20%)
  - Rarity/discontinuation status (15%)
  - Seller reliability (5%)
- Plain-English explanation generated by Claude API

**3. Web Dashboard**
- Live deal feed with filtering and sorting
- AI commentary on each listing
- Price history charts (90-day trend)
- User preference settings

**4. Alert System**
- Real-time email alerts for high-scoring deals (8+)
- SMS alerts for exceptional opportunities (9+)
- Daily digest of top 5 deals

**5. AI Chat Agent**
- Natural language queries against live data
- Examples:
  - "Find me a Rolex Submariner under $12,000 with box and papers"
  - "Is this eBay listing a good deal?" [pasted URL]
  - "Alert me if a Pepsi GMT drops below $18K"

## Database Schema

**Core Tables:**

```sql
-- Products
products (
  id: uuid,
  brand: string, -- "Rolex"
  model_family: string, -- "Submariner"
  reference_number: string, -- "126610LN"
  name: string,
  retail_price: integer, -- MSRP in USD
  discontinued: boolean,
  created_at: timestamp
)

-- Listings
listings (
  id: uuid,
  product_id: uuid,
  source: string, -- "chrono24", "ebay"
  source_id: string, -- original ID from source
  price: integer,
  currency: string,
  condition: string, -- "unworn", "excellent", "good"
  has_box: boolean,
  has_papers: boolean,
  url: string,
  title: string,
  seller_rating: float,
  seller_name: string,
  deal_score: float, -- 0-10 calculated
  deal_summary: text, -- AI-generated explanation
  scraped_at: timestamp,
  raw_data: jsonb
)

-- Price History
price_history (
  id: uuid,
  product_id: uuid,
  source: string,
  price: integer,
  recorded_at: timestamp
)

-- Users
users (
  id: uuid,
  email: string,
  tier: string, -- "free", "collector", "premium"
  alert_threshold: float, -- min deal score (e.g., 7.0)
  preferred_models: jsonb, -- ["126610LN", "116500LN"]
  max_price: integer,
  created_at: timestamp
)

-- Alerts
alerts (
  id: uuid,
  user_id: uuid,
  listing_id: uuid,
  channel: string, -- "email", "sms"
  sent_at: timestamp,
  opened: boolean
)
```

**Indexes:**
- `listings.product_id + scraped_at` (for filtering)
- `listings.deal_score` (for scoring queries)
- `price_history.product_id + recorded_at` (for trends)

## Monetization

### Tier Structure (Revised)

| Tier | Price | Features | Target User |
|------|-------|----------|-------------|
| **Free** | $0/month | 5 alerts/day, email only, ad-supported, affiliate links | Casual browsers |
| **Collector** | $29.99/mo | Unlimited alerts, real-time email, AI chat, no ads | Active buyers |
| **Premium** | $49.99/mo | + SMS alerts, priority scoring, deal concierge support | Serious collectors/flippers |

### Revenue Breakdown (Per Premium User)

**Subscription:** $49.99/month = $600/year

**Affiliate Commissions:**
- Average purchase: $15,000
- Commission rate: 2-3%
- Commission per sale: $300-450
- Purchase frequency: 2-3x/year = $600-1,350 annually

**Total LTV:** $600 (sub) + $850 (affiliate avg) = **$1,450/year**

### Channel Strategy

**Free Tier:**
- Banner ads (rate-limited, not obtrusive)
- Sponsored featured listings (clearly marked)
- Email digest: 1 sponsored placement at bottom
- Affiliate links on all deals

**Paid Tiers:**
- No ads
- Priority alert delivery
- Concierge support (Premium)

### Revenue Projections

**Year 1 Target:**
- Free users: 5,000
- Collector tier: 500 x $30 = $15K/mo
- Premium tier: 200 x $50 = $10K/mo
- Affiliate revenue: 700 paying users x 2 sales/year x $350 avg = $490K/year
- **Monthly recurring: $25K**
- **Annual revenue: ~$800K**
